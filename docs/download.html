Install SignalProof on macOS: Select Get macOS Beta, download the UNNOTARIZED.zip file from GitHub's Assets section (not the .sha256 checksum or source-code ZIP), extract it, and move SignalProof.app to Applications. Open it normally. If macOS blocks it, choose Done, then go to System Settings → Privacy & Security and select Open Anyway for SignalProof. Only approve apps you trust; never disable macOS security globally.

Beta security notice: This release is not signed with an Apple Developer ID certificate or notarized by Apple. Currently for Apple Silicon Macs only. Testing on additional Macs is ongoing. Report a problem.
